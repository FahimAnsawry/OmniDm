Install OmniDM

Version {{VERSION}} · Windows 10 and 11

It takes about 5 minutes. First you install the app, which does the downloading. Then you add the browser extension, which sends your browser's downloads to the app. No administrator rights are needed, and nothing you download leaves your PC.

Part 1

Install the app

The app keeps running in the tray (next to the clock) so downloads start at once.

  1. Unzip the download

    Right-click OmniDM-{{VERSION}}.zip and choose Extract All…, then Extract. Everything is in the OmniDM folder it makes. Don't run the setup from inside the zip.

  2. Run OmniDM-Setup-{{VERSION}}.exe

    Double-click it. If Windows shows "Windows protected your PC", click More info, then Run anyway. Windows shows this for new programs that aren't signed with a paid certificate yet.

  3. Accept the terms and click Next

    Tick I accept the terms and conditions. The install folder is fine as it is.

  4. Choose your options and click Install

    Keep Start OmniDM when Windows starts on: then the browser can always hand downloads to it. You can change these later in OmniDM's Settings.

  5. Finish

    When it says OmniDM is installed, keep Launch OmniDM now ticked and close the setup. OmniDM opens, and its icon appears in the tray.

    The setup also connects OmniDM to your browsers (it registers with Windows), and adds the omnidm-cli command for terminals and scripts.
Part 2

Add the extension to Chrome, Edge or Brave

The extension isn't in the browser stores, so you add it from its folder. It's the same folder for all three browsers.

  1. Move the OmniDM_chrome folder somewhere it can stay

    You'll find it in the Extension folder inside the unzipped OmniDM folder. Move it into Documents, for example. The browser keeps using this folder: if you delete it or move it later, the extension stops working.

  2. Open the extensions page

    Type this in the address bar and press Enter:

    Chrome: chrome://extensions  ·  Edge: edge://extensions  ·  Brave: brave://extensions

  3. Turn on Developer mode

    The switch is at the top right in Chrome and Brave, and on the left side in Edge.

    chrome://extensions
    ExtensionsDeveloper mode
    Load unpackedPack extensionUpdate

  4. Click Load unpacked and pick the folder

    Choose the OmniDM_chrome folder itself (the one with manifest.json inside), then Select Folder. OmniDM now shows in the list.

  5. Pin it to the toolbar

    Click the puzzle-piece icon next to the address bar, then the pin next to OmniDM. If the OmniDM icon has no red or amber !, it's connected to the app.

    Extensions
    OmniDM📌
    Some versions of Chrome show "Disable developer mode extensions" when they start. Close that message; don't click Disable, or OmniDM turns off.

  6. Try it

    Click any download link: OmniDM asks where to save it and downloads it, usually much faster. On a page with a video, point at the video and click OmniDM's Download button in its corner.

Part 3

Add the extension to Firefox

Firefox only keeps extensions that Mozilla has signed. Until OmniDM's is, Firefox removes it every time Firefox closes, and you add it again with these steps. Chrome, Edge or Brave work without this limit.

  1. Open the debugging page

    Type about:debugging#/runtime/this-firefox in the address bar and press Enter.

  2. Click Load Temporary Add-on…

    Open OmniDM\Extension\OmniDM_firefox in the unzipped folder and choose the manifest.json file in it.

    about:debugging
    Temporary Extensions
    Load Temporary Add-on…

  3. Pin it and try it

    Click the puzzle-piece icon in the toolbar, then the gear next to OmniDM, then Pin to Toolbar. Downloads now go to OmniDM, as in Chrome.

Help

If something doesn't work

A red ! on the extension's icon The browser can't find the app. Install it (Part 1). If it is installed, run the setup again and choose Reinstall.
An amber ! on the icon The app was found but didn't start. Open OmniDM from the Start menu; the next download connects to it again.
Downloads still go to the browser, or to Internet Download Manager If IDM is installed, turn off its browser extension (or "advanced browser integration"), so only one program takes the downloads. Also check that OmniDM isn't switched off: clicking its icon switches it off and on.
The extension disappeared In Chrome, Edge or Brave its folder was moved or deleted: put it back, or load it again (Part 2). In Firefox this happens each time Firefox closes (Part 3).
Updating The app updates itself: when a new version is out, OmniDM offers it. Your downloads pause and continue after the restart. The extension doesn't update itself: from the newest release on GitHub, download just OmniDM-Extension-Chrome-<version>.zip (or the Firefox one), unzip it, replace the contents of your OmniDM_chrome folder with it, then click the reload arrow ↻ on OmniDM's card in the extensions page.
Uninstalling Windows Settings → Apps → OmniDM → Uninstall. Then remove the extension in the browser's extensions page.
